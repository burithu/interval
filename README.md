# Interval

Repeating reminders for desk workers. Set an interval and active hours, and Interval nudges you to stand up, drink water, stretch or eat. Dismiss it and the timer restarts on its own.

Android only. Kotlin + Jetpack Compose. All data stays on the device.

## Status
In development. See [docs/PLAN.md](docs/PLAN.md) for milestones and [docs/SPEC.md](docs/SPEC.md) for the full spec.

## Build
Requires Android Studio (or JDK 17+ and the Android SDK).

```sh
./gradlew testDebugUnitTest   # unit tests
./gradlew assembleDebug       # debug APK in app/build/outputs/apk/debug/
```
